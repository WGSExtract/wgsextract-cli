Design system

Tokens and components for the redesigned app. Plain CSS custom properties and classes, no build step, no web fonts or CDNs (it works offline and loads nothing from third parties). Link design-system/wgse.css; switch light and dark with the moon/sun button above, or compare them side by side below.

Colour

Neutrals carry most of the interface; blue means “you can act here”; the brand magenta marks results worth noticing. Semantic colours are for status only, always paired with an icon or word so colour isn’t the only signal. Text colours meet WCAG 2.2 AA (4.5:1) on every surface in both themes.

Buttons

One primary button per view, labelled with what it does (“Make 2 files”, not “Submit”). Destructive buttons say what goes and are never the default in a dialog. Icon-only buttons need aria-label.

Status badges always have a word; icons are optional. File-type marks (.ft[data-ft]) are icon-only tiles; the type name goes in an .ft-label beside them, so it can be translated.

Dense tables

Compact rows (36 px), sticky headers, right-aligned tabular numbers. Add .table--stack and data-label on cells and each row becomes a card on phones; mark columns that don’t matter there with .hide-phone. Switch the viewport to Phone above to see it.

Use determinate progress whenever the server reports it (progress events on /v1/jobs/{id}/events). Commands with step resume show their steps, sized by their typical share of the time, so “47%” of a 3-hour job reads honestly.

Fix-it cards, callouts, toasts and empty states

Problems are cards that say what happened, why it matters and what to do, with the fix as a button. Never a raw error string or a script path. Raw details (error code, log) are one click away for advanced users.

Accessibility and localisation

  • Contrast: text ≥ 4.5:1, large text and UI parts ≥ 3:1, in both themes (checked with axe-core).
  • Keyboard: everything reachable with Tab, visible focus rings (:focus-visible), Escape closes overlays, arrow keys in tabs and the palette.
  • Touch: 44 px minimum targets on phones and coarse pointers.
  • Motion: honours “reduce motion”.
  • Screen readers: landmarks, labelled icon buttons, role="progressbar" with values, live region for toasts.
  • Localisation: no text in images or icons; layouts allow 40% longer strings (German, Portuguese); numbers and dates formatted per locale; sizes as “GB” with the locale’s decimal mark.
