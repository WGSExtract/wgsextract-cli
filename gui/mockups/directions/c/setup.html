Where should WGS Extract keep its files?

Reference genomes, results and logs go here. It can grow to 20–100 GB, so a roomy disk is best. Your genome files can stay wherever they are.

  • 412 GB free on Macintosh HD

Checking the analysis tools

These come with WGS Extract; nothing to install unless something is missing.

  • samtools, bcftools, htslib 1.21
  • Aligners: bwa-mem2, minimap2, Apple Silicon (Metal)
  • Haplogroups: Yleaf, HaploGrep
  • Java isn’t installed. Only GATK and PharmCAT need it; you can add it later from Settings.
