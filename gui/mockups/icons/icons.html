Design system

Icons and logomarks

One line style for everything: a 24 px grid, round caps and joins, drawn with currentColor and a 1.75 px stroke set in CSS (--icon-stroke). Icons never carry text, so nothing in them needs translating; the label always sits beside them. Click an icon to copy its markup.

Design system

App logomark: three options

The current icon is a helix and a toolbox; these keep the helix colours and drop detail that disappears at small sizes. Vote with a note on the one you prefer.

WGS Extract icons

Drawn for this app: file types, genealogy and analysis steps. Source files are in icons/wgse/.

Interface icons

A subset of Lucide (ISC licence, icons/lucide/LICENSE), whose 24 px round-cap style the domain icons follow. Add one by copying its SVG into icons/lucide/ and running python3 gui/mockups/icons/build_icons.py.
