What’s a VCF, and when would you want one?

VCF stands for Variant Call Format: a table of positions where DNA differs from the reference genome, listing the reference sequence, the variant sequence and the called genotypes. A whole-genome small-variant VCF usually has millions of rows; Call variants builds one from a BAM or CRAM.

At 148 MB instead of tens of gigabytes for the reads, a VCF is much faster to search and annotate. Many ancestry, export and drug-response tools can run on it, depending on which sites and reference calls the file includes, though it does not replace a clinical genetic test.

Because a VCF holds no reads, it can’t be realigned to another reference or called again with a newer caller. A plain VCF also doesn’t say whether a position it leaves out matched the reference or wasn’t read at all, so keep the BAM or CRAM it came from if you can.
