What are DNA-test files for?

Testing companies such as 23andMe, AncestryDNA and MyHeritage don’t read your whole genome. Their chip reads about 600,000–700,000 chosen markers, and you can download the result as a raw-data file. Matching sites compare these files to find relatives who share stretches of DNA with you.

A whole genome holds nearly all of those markers, so WGS Extract can write the file each site expects, without a new test. Each site has its own database, so uploading to several finds different relatives.

Uploading shares the person’s genotypes with that company: read its privacy terms first.

Where will you upload?

These companies don’t take uploads. Make their format only for another tool that reads it.

Each file holds the markers on that company’s chip, read from this genome. WGS Extract picks the chip version each site expects.
