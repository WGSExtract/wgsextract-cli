What changes when you convert?

The reads stay the same; only the way they’re stored changes.

BAM to CRAM
Compresses alignment records, often using differences from the reference genome. Size varies with the data. A lossless conversion preserves read records, but needs the exact reference to decode them, here hs37d5. Keep that reference available.
BAM to BAM
About the same size. Sorts the reads, or rewrites a file a tool won’t accept.
To FASTQ
Exports retained read sequences and base qualities without placements. Paired-end data usually makes R1 and R2 files. Align again for coordinate-based analysis; this cannot restore discarded qualities or original sequencer signals.

Converting doesn’t change the genome build. To move from GRCh37 to GRCh38, realign instead.
