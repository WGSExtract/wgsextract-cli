Pharmacogenomics

vcf/pharmcat

PharmCAT reads the genes that affect how some medicines work, such as CYP2C19 and SLCO1B1, and reports each gene’s type with the published dosing guidance.

ForHelen·VCFhelen-mcdonald.deepvariant.vcf.gz
Missing positionsHelen’s VCF lists only where she differs, so a position it doesn’t mention matches the referenceabsent_to_ref
Genes typed elsewhereAdd CYP2D6 or HLA results from typing, which PharmCAT can’t read from a VCFoutside_call
