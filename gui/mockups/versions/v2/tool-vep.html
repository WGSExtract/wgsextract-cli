Before it starts

Space on Macintosh HDNeeds about 31 GB for the cache, 0.6 GB for the result; 412 GB freeOK
The VEP cache isn’t installedvep-rs needs its GRCh38 cache: 26 GB to download, 31 GB on disk. Install it once from Reference data.
Reference data
wgsextract vep run --input {{bundleWorkspace}}/genomes/helen-mcdonald/helen-mcdonald.deepvariant.vcf.gz \
  --engine vep-rs --preset everything --format vcf
