Why make a GRCh38 copy?

The reference genome comes in versions, called builds. Gordon’s BAM is on GRCh37, from 2009; most labs, tools and databases now use GRCh38, from 2013. A gene sits at different positions in the two, so a file only works with tools that expect its build.

Realigning places every read again on GRCh38. It takes a few hours, and the reads themselves don’t change.
