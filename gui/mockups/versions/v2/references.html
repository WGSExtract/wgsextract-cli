What’s a reference genome, and why are there several?

A reference genome is a named set of DNA sequences used as a coordinate map. Sequencers produce reads; alignment places them against that map, and variants describe differences from it. A reference is not an ideal or “normal” person.

Different builds number positions differently: GRCh37 (2009), GRCh38 (2013) and T2T-CHM13, which fills gaps left in earlier builds. CHM13 itself has no Y chromosome, though some bundles add a separate complete Y. Bundles within the same build can also include different decoys and alternate sequences.

Opening a CRAM requires the exact reference bundle it was made with; another bundle from the same build won’t work. Check the file’s header, or ask the lab if it isn’t clear which bundle was used.
