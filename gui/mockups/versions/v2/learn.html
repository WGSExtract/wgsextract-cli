Unsure what kind of file the lab sent you?

Start with Your file journey. A BAM (Binary Alignment Map) keeps all aligned reads (~60–100 GB); a VCF (Variant Call Format) lists only differences from the reference (a few hundred MB). Both are research files rather than clinical diagnoses.
