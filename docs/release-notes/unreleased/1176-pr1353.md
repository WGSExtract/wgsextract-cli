## New

- `report --pgx-context FILE` reviews the medications a person lists in a
  local TOML file against CPIC guidance (CPIC database v1.61.0, CC0, pinned;
  first use needs `--download`; the list is never uploaded). Guidance is given
  only when the pharmacogenomic calls it rests on are confident: weak, missing
  reference, unresolved Cyrius and conflicting ambiguous calls are withheld,
  and unsupported drugs, populations and results say so. A CPIC-quoted rule
  shows paroxetine's possible CYP2D6 phenoconversion beside the genetic
  phenotype. The review is labelled not a prescription, and the manifest
  records the CPIC release and the effective medication list
  ([#1176, CPIC medication review](https://github.com/WGSExtract/wgsextract-cli/issues/1176)).

## Changed

- The experimental report finding type now accepts `medication_review` as a
  section and `Not a prescription; review with a clinician.` as a disclaimer.
  These values are for medication-review findings; other sections share the
  type but do not use the new values. The widened keys are:
  - `wgsextract.report/1:sections.acmg_research.findings[].section`
    and `wgsextract.report/1:sections.acmg_research.findings[].disclaimer`
  - `wgsextract.report/1:sections.ancestry.findings[].section`
    and `wgsextract.report/1:sections.ancestry.findings[].disclaimer`
  - `wgsextract.report/1:sections.carrier_screening.findings[].section`
    and `wgsextract.report/1:sections.carrier_screening.findings[].disclaimer`
  - `wgsextract.report/1:sections.clinvar.findings[].section`
    and `wgsextract.report/1:sections.clinvar.findings[].disclaimer`
  - `wgsextract.report/1:sections.lineage.findings[].section`
    and `wgsextract.report/1:sections.lineage.findings[].disclaimer`
  - `wgsextract.report/1:sections.microarray.findings[].section`
    and `wgsextract.report/1:sections.microarray.findings[].disclaimer`
  - `wgsextract.report/1:sections.overview.findings[].section`
    and `wgsextract.report/1:sections.overview.findings[].disclaimer`
  - `wgsextract.report/1:sections.pharmacogenomics.findings[].section`
    and `wgsextract.report/1:sections.pharmacogenomics.findings[].disclaimer`
  - `wgsextract.report/1:sections.structural_variants.findings[].section`
    and `wgsextract.report/1:sections.structural_variants.findings[].disclaimer`
