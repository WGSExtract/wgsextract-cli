## New

- `vcf compare` reports local small-allele and genotype agreement across
  callsets, or selects shared family alleles with optional strict gVCF
  exclusions and BED scoping. It can also write an indexed single-sample VCF
  annotated with each callset's state
  ([#1295, local VCF concordance](https://github.com/WGSExtract/wgsextract-cli/issues/1295)).
