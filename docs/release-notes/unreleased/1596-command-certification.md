## New

- CLI help, API discovery and MCP tool descriptions show each command's
  certification level. Detailed help and the published certification reference
  link to the evidence. Result manifests record the level at run time. Set
  `certification_notices = false` in `config.toml` to hide Tested and
  Experimental notices ([#1596, command certification](https://github.com/WGSExtract/wgsextract-cli/issues/1596)).
