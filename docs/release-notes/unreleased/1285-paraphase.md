## New

- `typing paraphase` calls copy number and haplotypes at paralogous loci
  such as SMN1/SMN2 and PMS2 from PacBio HiFi whole-genome reads. It writes
  TSV and JSON calls, retains the engine's raw files, and labels ONT calls
  experimental and unvalidated ([#1285, long-read paralog typing](https://github.com/WGSExtract/wgsextract-cli/issues/1285)).
